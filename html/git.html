Основные команды Git и Терминала

  • ls - расшифровывается как "List files in the directory", что переводится как "перечислить все файлы в папке" или "вывести на экран список файлов в папке".
  • cd - расшифровывается как "Change directory", что переводится как "сменить папку" или "перейти в другую папку".
  • pwd - расшифровывается как "Present working directory", что переводится как "текущая рабочая директория". То есть команда pwd показывает, в какой сейчас папке мы находимся.
  • mkdir - расшифровывается как "Make directory", что переводится как "создать папку".
  • mv - расшифровывается как "Move", что переводится как "переместить", "передвинуть". С помощью нее можно переместить или переименовать файл или папку.
  • git init - создание нового локального репозитория Git в текущей папке.
  • git clone - копирование удаленного репозитория на локальный компьютер.
  • git status - проверка состояния файлов (отслеживаемые, измененные, подготовленные к коммиту).
  • git add - добавление изменений в индекс (подготовка файлов к сохранению).
  • git commit -m "сообщение" - сохранение зафиксированных изменений в истории проекта с описанием.
  • git push - отправка локальных коммитов в удаленный репозиторий (например, на GitHub).
